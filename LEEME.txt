STREAMZONE + MERCADO PAGO (MODO PRUEBA)

ARCHIVOS:
- index.html
- api/config.js
- api/process_payment.js

ANTES DE PROBAR:
1. En Vercel abre tu proyecto StreamZone.
2. Ve a Settings > Environment Variables.
3. Crea:
   MP_PUBLIC_KEY = tu Public Key DE PRUEBA de Mercado Pago
   MP_ACCESS_TOKEN = tu Access Token DE PRUEBA de Mercado Pago
4. No pegues el Access Token dentro de index.html ni lo compartas.
5. Vuelve a desplegar esta carpeta/ZIP completa en Vercel.
6. Agrega un producto > Carrito > completa nombre y correo > Mercado Pago > Comprar ahora.
7. Aparecerá el formulario seguro de tarjeta de Mercado Pago dentro del carrito.

IMPORTANTE:
- Usa credenciales y tarjetas DE PRUEBA mientras configuramos.
- La API recalcula el total en el servidor usando los precios de StreamZone.
- Este proyecto todavía guarda los tickets/pedidos del panel en localStorage del navegador.
  Para sincronizarlos entre dispositivos necesitaremos una base de datos y webhook.
